## Rust

Solutions implemented using Rust Edition 2024, covering:

- Ownership, borrowing, and lifetimes
- Traits, generics, and macros
- Data structures and algorithms
- Functional programming and iterators
- Concurrency and parallel processing
- Dynamic programming
- Recursive algorithms and backtracking
- Interpreter implementation
- Error handling and testing

## Running Tests

Each Rust exercise is an independent Cargo project.

```bash
cd rust/knapsack
cargo test -- --include-ignored
```
